## From catalogue to engineering decision

JoveWorks keeps the method the same even when the subject changes. Load the
catalogue provided for the work, use its formulas alongside the built-in nodes,
and make the requirements visible as part of the graph. A fixed input computes
one case; a range or list turns the same graph into a design study.

The NodeBook is a reading-order view of that graph, not a separate document.
Organise the canvas into sections, add the outputs that support the decision,
and export the result without copying values into another tool.
